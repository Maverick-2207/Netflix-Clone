# 🎬 Netflix Clone – HTML & CSS

A fully responsive **Netflix homepage clone** built using **only HTML and CSS** as part of my frontend development journey. While inspired by Netflix’s UI, this is **not a pixel-perfect replica** — I’ve added my own creative touches and layout customizations.

## 🌟 Key Features

- 📱 Fully responsive layout across all screen sizes  
- 🎨 Custom hero section with curved background and overlay  
- 🧩 Pure HTML & CSS – no JS, no frameworks  
- 🧠 Personalized structure, not a blind copy  
- 🧭 Clean navigation bar with logo and CTA buttons  
- 🖼️ Optimized background scaling using `background-size: contain`  
- 💡 Uses CSS positioning and media queries for responsiveness
